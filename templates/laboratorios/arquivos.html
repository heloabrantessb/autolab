Aprender: organizar por extensão

Uma equipe recebeu documentos, planilhas e imagens na mesma pasta. O objetivo é separar os arquivos em categorias, preservar todos os conteúdos e registrar de onde cada arquivo veio.

A extensão é a parte final do nome, como .txt ou .csv. Ela orienta a classificação; não comprova o formato real do conteúdo.

Código Python: identificar a categoria

Este trecho classifica um nome de arquivo. Ele não extrai ZIPs nem grava arquivos; a organização completa precisa também de validação, tratamento de colisões e relatório.

from pathlib import Path

def categoria(nome):
    # .lower() permite reconhecer também extensões como .JPG.
    extensao = Path(nome).suffix.lower()
    categorias = {
        "Documentos": {".pdf", ".doc", ".docx", ".txt"},
        "Planilhas": {".csv", ".xls", ".xlsx"},
        "Imagens": {".png", ".jpg", ".jpeg"},
    }
    for grupo, extensoes in categorias.items():
        if extensao in extensoes:
            return grupo
    # Inclui arquivos sem extensão.
    return "Outros"

print(categoria("clientes.csv"))  # Planilhas

Desafio: preservar arquivos com nomes iguais

Os arquivos comunicado.txt e subpasta/comunicado.txt devem ir para Documentos. Como manter os dois sem sobrescrever o primeiro?

  • Classifique extensões sem diferenciar maiúsculas e minúsculas.
  • Resolva nomes repetidos com sufixos, como comunicado_2.txt.
  • Registre caminho original, nome de saída, categoria e status no inventário.
  • Verifique se os seis arquivos continuam presentes após a organização.

Dica: contar apenas os nomes não basta; compare também o conteúdo dos dois documentos. A validação automatizada virá com os testes locais do exercício, sem executar código de participantes no servidor.

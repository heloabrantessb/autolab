Exercício: organização de arquivos

Complete três funções Python para classificar arquivos, preservar nomes repetidos e criar um inventário.

Nível: iniciante · Pré-requisitos: funções, conjuntos, laços e extensões · Duração sugerida: 25 minutos.

Problema

Uma equipe recebeu seis arquivos misturados em um ZIP. Dois comunicados têm o mesmo nome e conteúdos diferentes. Preserve todos os arquivos e registre sua origem no relatório.

Baixar exercício Python

O pacote inclui instruções, starter.py, apoio de execução, testes e o ZIP fictício. Use Python 3.12 ou superior; nenhuma instalação de biblioteca é necessária.

Passo a passo

  1. Descompacte o pacote em uma pasta nova e leia README.md.
  2. Complete categoria usando a extensão em minúsculas.
  3. Complete nome_unico com sufixos incrementais e comparação sem distinguir maiúsculas.
  4. Complete linha_inventario preservando o caminho original e indicando se o nome mudou.
  5. Abra o terminal na pasta descompactada e rode os testes; depois gere uma saída com nome novo.
python tests/verificar.py
python starter.py --saida resultado.zip

Os testes inicialmente falham porque os TODOs ainda não foram resolvidos. Ao completar as funções, os seis testes devem passar. O apoio aceita somente o ZIP fictício original, organiza o resultado e grava o CSV.

Critérios de conclusão

  • Seis arquivos: Documentos=3, Planilhas=1, Imagens=1, Outros=1.
  • Os dois comunicados existem com conteúdos distintos; o segundo recebe sufixo.
  • relatorio.csv tem seis linhas de dados, caminhos originais, saída, categoria e status.
  • ZIP de entrada e saídas existentes permanecem inalterados.

Desafio

Explique os casos foto.JPG e LEIA-ME. Teste uma colisão quando a.txt e a_2.txt já estão usados. Por que apenas contar os nomes não comprova que os conteúdos foram preservados?

Dica: use Path(nome).suffix.lower() para a extensão e um conjunto com casefold() para os nomes usados. Se uma saída já existir, escolha outro nome em --saida.
